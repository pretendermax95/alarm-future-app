# Future Alarm

Будильник будущего — минималистичное Android-приложение с современным интерфейсом, которое помогает проснуться вовремя и делает утро чуть более технологичным.

## Возможности
- современный тёмный интерфейс;
- кнопка установки будильника;
- кнопка остановки;
- лёгкий старт для дальнейшей разработки.

## Технологии
- Kotlin
- AndroidX / Material 3
- Gradle

## Как запустить
1. Откройте проект в Android Studio.
2. Синхронизируйте Gradle.
3. Запустите приложение на эмуляторе или устройстве.

## Сборка APK
```bash
./gradlew assembleDebug
```

Готовый APK будет доступен в папке:
```text
app/build/outputs/apk/debug/
```
